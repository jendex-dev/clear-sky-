САЙТ ФРАКЦИИ «ЧИСТОЕ НЕБО»

Состав: index.html + папка music (revengeance.mp3, stand-by.mp3). Держите их вместе.
Открыть локально: двойной клик по index.html.
Выложить для всех по ссылке: Netlify Drop (app.netlify.com/drop), GitHub Pages или любой хостинг статических сайтов. Загрузите всю папку.

ДО ПУБЛИКАЦИИ откройте index.html в блокноте и найдите блок CONFIG:
  LEADERS — впишите свой ник Roblox (тогда в магазине появится панель генерации кодов сбора).
  Коды сбора теперь хранятся в Firestore (коллекция codes), SECRET больше не нужен.
  Старые 6-символьные коды не работают: создайте новые 8-символьные.

ОДЕЖДА
Форма по рангу лежит в папке clothes: lvl0 (без пака), lvl1 новичок, lvl2 опытный, lvl3 ветеран, lvl4 мастер.
Чтобы заменить форму, подмените PNG с тем же именем (шаблон Roblox 585x559, прозрачный фон).

БАЗА ДАННЫХ (Firebase)
Правила доступа лежат в FIRESTORE_RULES.txt: вставьте их в Firebase, Firestore Database, вкладка Rules, нажмите Publish.
Если меняете ник лидера в CONFIG (LEADERS), поменяйте его и в правилах (isLeader), в виде ник@clear-sky.example строчными буквами.

ЛИДЕРЫ
Владелец сайта задаётся ником в CONFIG (LEADERS) и в правилах (isOwner). Остальных лидеров владелец назначает на сайте:
Настройки, Аккаунты, нажать на игрока, кнопка «Назначить лидером». Лидеры выдают коды сбора, меняют очки и заслуги и забирают купленные предметы.


ОБНОВЛЕНИЕ: заместитель, волонтёры, оформление, журнал аудита
- Заместитель лидера: владелец назначает его в Настройки → Аккаунты (кнопка «Назначить заместителем»).
  У заместителя те же возможности, кроме назначения других заместителей.
- Волонтёры: вкладка «Зарегистрироваться как волонтёр» на экране входа. У них репутация (0–2000)
  вместо очков и заслуг и страница «Расценки» вместо магазина. Репутацию выдают лидер и заместители.
- Оформление: Настройки → Оформление (синее/зелёное), выбор сохраняется в профиле.
- Журнал аудита: Настройки (лидер и заместители) — кто сколько получил и выдал, список событий.
- Обязательно заново опубликуйте FIRESTORE_RULES.txt (Firebase → Firestore → Rules → Publish).

РОЛИ ИО И ТЕМА ИО
- Лидер ИО: только выдаёт очки (без снятия) и создаёт коды сбора, видит список аккаунтов. Назначает его владелец сайта.
- Член ИО: метка в профиле. Назначают лидер ИО, заместители и владелец (кнопка «Назначить членом ИО»).
- Тема «ИО»: Настройки → Оформление. Светлее стандартной, на камуфляже рисунок ДНК.
- Новая песня old cavalry: music/old-cavalry.mp3.
- Снова опубликуйте FIRESTORE_RULES.txt (добавлена коллекция members и права лидера ИО).

КОДЫ СБОРА: теперь при создании кода нужно вписать ники участников. Код принимает только их.
Опубликуйте FIRESTORE_RULES.txt заново (код обязан содержать список ников).

ГЛАВНЫЙ ПРИКАЗ: вкладка в меню у всех. Создаёт и меняет только владелец (кнопка «Создать приказ» / «Изменить приказ»),
в приказе: заголовок, описание, задачи с нужным количеством и прогрессом, награда, срок. Обновляется у всех сразу.
Опубликуйте FIRESTORE_RULES.txt заново (добавлена коллекция orders).
